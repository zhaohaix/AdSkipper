# 跳广告 · AdSkipper

一个 Android 小工具：**自动点掉 App 开屏广告、关掉应用内广告弹窗**。

靠系统公开的无障碍（Accessibility）能力实现——不注入进程、不 hook、不 root、**不联网**。

> 仅供个人自用与小范围测试。使用前请阅读文末的[免责声明](#免责声明)。

---

## 它做什么

| 场景 | 做法 |
|---|---|
| 开屏广告 | 找「跳过 / 跳过 5 / skip」文字，点掉 |
| 弹窗广告 | 在“看起来是广告”的窗口里，点 id 含 close/dismiss 的按钮 |
| 认不出的广告 | 学习模式：你手动点一次，它记住，以后自动点 |

## 它不做什么

- ❌ 不申请网络权限（安装包里根本没有 `INTERNET`），数据不出手机
- ❌ 不注入、不修改其他 App 的内存
- ❌ 不模拟滑动、不刷量、不做自动化脚本
- ❌ 不在支付、输入法、系统界面上动作

---

## 功能

- **白名单**：只处理你指定的 App；也可以开「调试模式」处理全部
- **学习模式**：手动点一次，记住这个按钮（按包名 + 窗口 + 资源 id 匹配）
- **稳定模式**：一键完成“保活 + 掉线自愈 + 申请忽略电池优化”，用一点电换稳定
- **各机型指南**：内置 vivo / 小米 / 华为 / OPPO / 三星 的无障碍开启与保活路径

## 安全设计（防误伤）

工具最怕的不是“跳不掉”，而是“乱点”。所以有多层限制：

| 限制 | 作用 |
|---|---|
| 滑动后 700ms 内不点 | 不影响刷信息流 |
| 键盘弹出 / 刚输入文字 / 焦点在输入框 → 不点 | 不影响打字 |
| 支付、收银台类窗口整窗跳过 | 不碰钱 |
| 「支付 / 验证码 / 清除 / 搜索」类文字节点不参与匹配 | 不点错按钮 |
| 只点小尺寸、且在屏幕内的控件 | 不点整块卡片 |
| 一分钟点超 6 次 → 熔断 5 分钟 | 防失控循环 |
| 系统界面、输入法进程完全不参与 | 不碰系统 |

## 安装

1. 到 [Releases](../../releases) 下载最新的 `apk`
2. 手机允许「未知来源安装」后安装
3. 打开 App，按首页提示开启无障碍

详细步骤见 [使用说明](测试说明.md)。

## 自己构建

需要：Android Studio（或 JDK 17+ + Android SDK 36）、网络可访问 Maven 仓库。

```bash
git clone <this-repo>
cd AdSkipper
# 用 Android Studio 打开，或：
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/`。

> 工程路径请避免中文，AGP 会拒绝；如果做不到，`gradle.properties` 里已经加了 `android.overridePathCheck=true`。

## 已知限制

这些不是 bug，是当前方案的天花板：

- **美团 / 美团外卖**：打开即把第三方无障碍服务踢掉（对方安全策略）
- **纯图片 / 自绘广告**：按钮在控件树里不存在，识别不到
- **数字在前的跳过按钮**（如 `5跳过`）：暂未支持，可手动学一次
- **部分游戏**：竞技类会把“无障碍开启”当风险信号，建议游戏时关闭

## 隐私

- 无 `INTERNET` 权限，无法联网
- 所有配置（白名单、学习记录）只存在本机 `SharedPreferences`
- 不收集、不上传任何数据
